# 🤖 Talk With Baba – AI QnA Bot

An AI-powered conversational chatbot built using Python, Streamlit, LangChain, and Google Gemini AI.

This project allows users to chat with an AI assistant that remembers conversation history and responds in real time.

---

# 🚀 Features

- 💬 Real-time AI Chat
- 🧠 Conversation Memory Support
- ⚡ Powered by Google Gemini AI
- 🎨 Simple Streamlit UI
- 🐍 Beginner-Friendly Python Project

---

# 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- Google Gemini API
